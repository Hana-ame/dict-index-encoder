# 词典编号编码器 · 中文码表 2 万字

把词元映射为永久递增的编号，原文与密文双向实时联动。数据保存在浏览器本地。

**在线体验：** https://hana-ame.github.io/dict-index-encoder/

## 词元怎么切

- 一串连续的 `a-z` 字母算作一个词元（`hello` → 1 个）
- **每个汉字各算一个词元**（`真空中的翻转` → 5 个，各拿一个编号）
- 空格与换行原样保留

## 三种密文格式

原文语言与密文格式互不绑定，同一份词表可互换输出：

| 格式 | 编号 1 / 2 / 3 的输出 |
|---|---|
| 数字 | `1` `2` `3` |
| 字母 | `a` `b` `c`（1→a、26→z、27→aa…） |
| 汉字 | 码表第 1 / 2 / 3 个字（CJK 基本区 U+4E00–U+9FFF，共 20992 字） |

词表为空时输入 `一二三四五`：

| 格式 | 密文 | 反向还原 |
|---|---|---|
| 数字 | `1 2 3 4 5` | `一二三四五` |
| 字母 | `a b c d e` | `一二三四五` |
| 汉字 | `一丁丂七丄` | `一二三四五` |

数字 / 字母格式下，词元之间用空格分隔（连续汉字也要分隔，否则数字会粘连）；还原时相邻汉字之间不再补空格，因此能还原成连续中文。

词表**只增不减**、跨格式共享、跨多次输入永久累积；**打乱词表**会重新分配编号，旧密文将无法还原。

## 说明

单文件静态页面，无构建、无依赖、无后端。`index.html` 即全部内容。

## 部署

由 GitHub Actions 自动发布，本地无需任何操作：

- 工作流：`.github/workflows/deploy.yml`
- 触发：推送到 `main`，或在 Actions 页面手动 `Run workflow`
- Pages 发布源：**GitHub Actions**（不使用 `gh-pages` 分支）

更新后推送即可：

```bash
git add -A && git commit -m "your change" && git push origin main
```
